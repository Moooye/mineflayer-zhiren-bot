# 多账号正版挂机机器人（Mineflayer）

基于 [Mineflayer](https://github.com/PrismarineJS/mineflayer) 的多账号 Minecraft 挂机机器人，支持正版（微软设备码）与离线两种登录方式，自带 Web 控制面板，一条指令都不用手写配置即可上手。

## 功能总览

- **多账号错峰上线**，单账号故障/放弃不影响其他账号
- **回复玩家走 /msg 私聊**：游戏内指令的回执默认用 `/msg <玩家> <内容>` 私聊到人（面板控制台日志会同步一条，并标注「（私聊：msg）/（公屏）」）。服务器若回“未知命令/没权限”（插件锁指令、禁了 msg），会**自动换下一种写法**：msg → tell → w，三种都被拒才改成公屏回（带 `[给 玩家]` 前缀），10 分钟后再从 msg 试起。想固定成别的写法：配置 `reply.whisperCommands`（数组，自己配的排最前）/ `reply.fallbackChat:false`（永不用公屏）
- **卡片上直接看 TPS / Ping**：每张机器人卡片在「在线」状态下方有一个红框，左边是**服务器 TPS**（用服务器世界时间 tick 在 10 秒滑动窗口里估算，满速 20.0；服务器卡住会如实变低），右边是**本连接的 Ping**（服务器广播的 player_info 延迟，和游戏里 TAB 看到的一致，单位 ms）。数字拿不到时显示 `-`，绝不编数；颜色只是辅助，数值才是准的（绿 ≥19 TPS / <100ms，黄 15–19 / <200ms，红 更低 / 更高）
- **一个账号可以挂到多台服**：同名账号能分别加到不同的服务器，**每加一个就多一张卡片**（卡片标题后面标 `@服务器`，名字相同也能分得开；控制台账号下拉里也按 `账号@服:端口` 分开选）。面板「默认服务器 IP/端口」填了就写进新账号，不填就用默认服务器；**同一台服务器上重复添加会提示“账号已存在”**（同 IP + 同端口才算同一台，域名大小写不区分）。卡片上的按钮、启用/停用、删除都只影响你点的那一张卡。注意：正版账号同一时间只能在一个服务器在线，两处都开着会互相顶下线——用「停用」只留一个在线（停用 = 断开且不再自动重连，重启也不拉起来）
- **开箱即用**：自带 Node 运行时（`runtime\node.exe`）与依赖（`node_modules\`），新电脑双击 `start.bat` 即可，无需安装 Node.js/npm
- **正版设备码授权**（令牌缓存 `auth-cache/`，之后自动免授权）；支持离线模式（仅离线服）
- **断线指数退避自动重连**（2s→封顶 5 分钟 + 抖动），识别封禁/白名单（停止重试）与维护（长冷却）
- **服务器不在线自动等待（不盲目直连）**：断线后先探一次服务器（服务器列表 ping，和客户端“刷新服务器”同一条协议），**不在线就保持离线、不再发登录包**，只按间隔探测（默认 10 秒）；一探测到服务器恢复在线立刻自动重连。配置项 `serverWatch`（`enabled:false` 关掉，回到“按退避盲连”）
- **防 AFK**：随机间隔随机动作（挥手/转头/跳/走回原位），不机械常驻按键
- **自动进食**：饥饿低于阈值自动取食，排除腐肉/毒食
- **实体过滤（可选，默认关）**：`!实体过滤 开/关`。**关着的时候什么都不拦**（`bot.entities` 跟原版完全一样）；开启后能判定类型的怪会被真实清出内存，只留玩家/掉落物（另有少量还没解析出类型的空壳靠定时清扫兜底）。**身边的实体一律保留**（默认 8 格，见 `perf.entityFilter.keepNearRadius`），所以开启后 `!攻击` 照常生效；远的一样过滤掉，内存开销被“身边八格”锁死（再有 `keepNearMax` 上限兜底）。每个实体包会多一次拦截判断（CPU 略升），所以按需再开，配置项 `perf.entityFilter`
- **死亡处理**：死亡/重生日志，重生后自动 `home`
- **聊天/指令全排队限流**（令牌桶 + 去重 + 优先级），防刷屏
- **传送队列**：`tpa`/`tpahere`/`home 1`/`sethome 1`/`delhome 1` 一次一个、等待到达/确认（家名不填一律用 `1`）
- **自动接受传送**：**owners / 传送白名单管理员（tpAdmins）/ 白名单组（friends）/ 传送白名单成员（tpPlayers）** 对机器人 `tpa`/`tpahere` 时自动执行 `/tpaccept`；黑名单与其他玩家一律忽略，识别不了的请求文案会写日志便于适配（配置 `autoAcceptTpa`，默认开启）
- **盯人检测（!检测）**：`!检测 <玩家1> <玩家2>` —— 盯着玩家1，**他一离开服务器就自动对玩家2执行 `/tpa`**（两个参数都必填，不再有默认目标）。下线信号用 mineflayer 的 `playerLeft`（玩家列表里消失，与服务器文案无关），并用「X 离开了游戏」类文案兜底；触发动作走传送队列（排队+限流），不直接刷屏。**只触发一次，触发完就自动解除，要再盯得重新发命令**；**同一时间只按最新那条检测算**（重复输入 `!检测` 会顶掉之前那条）；多个机器人同时收到命令时只由第一个发现的执行，不会一起 tpa。`!检测` 看当前在盯谁，`!检测 关 [玩家1]` 取消。**本指令仅私聊生效。**
- **指令分「仅私聊」与「公屏可用」两类（重要）**：公屏是服务器**广播**的，同一台服务器上每个机器人都能收到同一条指令，若不加区分就会「几个机器人各做一遍 + 各回一条」，像 `!回家`/`!tpa`/`!清空` 还会互相撞位置、互相捡走对方丢出的物品。因此：
  - **仅私聊（30 条，公屏发来一律静默忽略，不执行也不回复）**：`
    !状态`、`!跟随`、`!去`、`!移动`、`!攻击`、`!瓶子`、`!左转`、`!右转`、`!俯视`、`!瞄`、`!装备`、`!卸甲`、
    !右键`、`!持续右键`、`!种树`、`!切`、`!副手`、`!丢`、`!下车`、`!回家`、`!tpa`、`!tpahere`、
  `!设家`、`!删除家`、`!清空`、`!指令`、`!检测`、`!存箱`、`!取`、`!开箱`；
  - **公屏可用（15 条，全体开关类，一起触发本来就是对的）**：`
    !停止`、`!重连`、`!关服`、`!afk`、`!进食`、`!实体过滤`、`!说`（本身有跨机器人去重，只会 1 个机器人发言），以及 8 条白名单管理指令（`!白名`、`!清白`、`!白名单`、`!授权`、`!传送管理员`、`!传送白名`、`!传送清白`、`!传送名单`）。
  - 私聊天然只发给一个机器人，所以「仅私聊」的指令不会重复触发。面板白名单勾选区会给这类指令标出橙色**「需私聊」**角标。
- **权限组（四个组）**：①**组1 最高权限**（`owners`，配置文件里设置，默认就是你自己）可用全部指令；②**组2 白名单组**（`friends`，**由你添加**）只能使用 `whitelist.friendCommands` 里列出的那些（面板勾选，默认 16 条：状态/停止/去/跟随/移动/左转/右转/回家/设家/删除家/tpa/tpahere/进食/瓶子/攻击/afk），**还可为每个人单独设置个人权限**（面板下拉多选，个人清单优先于公共勾选，选「全部(*)」= 放行所有非管理指令）；③**组3 传送白名单管理员**（`tpAdmins`，由你指定）= **白名单组的全部指令** + 管一张**传送白名单**（`tpPlayers`）：名单管理用 `!传送白名 <玩家>` / `!传送清白 <玩家>` / `!传送名单`（他们能给别人的唯一权限就是“对方 tpa/tpahere 时机器人自动 /tpaccept”）；④**组4 公屏组**（面板开关）：开启后该玩家可以在**公屏**发 `!` 指令触发原本「仅私聊」的指令（每个机器人都会各自执行一次）；**重连/关服/授权/加白名单等管理类仍然只归 owners**。同一个人既在白名单又被设成管理员时，两边权限叠加（不会反而用不了）。其他人默认不响应。
- **箱子 / 木桶自动存取（!存箱 / !取 / !开箱）**：走到仓库点打开箱子按规则存取。`!存箱`（按 `chest.deposit` 名单存）、`!存箱 全部`（除 `chest.keep` 保留名单外全存）、`!取 <物品> [数量]`（**物品名直接写中文**，如 `!取 铁锭 64`、`!取 钻石`；也兼容英文 ID `iron_ingot`；数量留空 = 尽量取）、`!开箱`（只看看有什么）。支持箱子/陷阱箱/木桶；仓库点可配坐标 `chest.station`，或只配 `chest.stationAlias` 走服务器 `home` 指令回家再找；还可配 `chest.autoScheduleMs` 定时自动存箱。**这三条指令仅私聊**（多个机器人抢同一个箱子窗口必然互相顶掉）。参考了 mineflayer 官方 `examples/chest.js` 的标准做法
- **自动登录 / 注册（autoAuth）**：适配有登录插件的服务器（AuthMe 类）。进服后按服务器提示自动判断：命中"请登录"类文案发 `/login <密码>`，命中"请注册"类发 `/register <密码> <密码>`；识别到"登录成功/欢迎回来"即确认完成。**安全设计**：没配密码则整个功能**不启用**（绝不发空密码）；同一条提示不重复发、两次尝试至少间隔 8 秒（防被判刷屏）；密码错误或超过 5 次立即放弃并告警（不拿错密码死循环）；**日志与面板里密码一律显示 `***`**，不落盘明文
- **聊天/私聊日志**按天落盘；可选 **Web 只读状态面板** 与 **Webhook 通知**
- **Web 控制面板（零依赖，浏览器打开即用）**：每账号一张卡片——状态/血量/坐标/维度/**服务器 TPS / Ping**/**背包+装备栏+副手实时显示**（物品名全中文，长名两行、悬停看全名和数量）；按功能分组的操作按钮（挂机·自动 / 战斗 / 移动朝向 / 家传送 / 箱子 / 运行控制 / 账号切换与删除）；白名单可视化管理（公共指令勾选 + 个人权限下拉多选 + 公屏组开关 + 黑名单）；双日志窗口（控制台/公屏，北京时间时间戳）；**白名单多机器人共享**（一处改动全体同步）；支持面板直接添加/删除机器人、正版⇄离线一键切换
- **控制台日志可一键刷新**：面板右下「控制台日志」栏右上角有**刷新**按钮，点它只重画这一栏日志（并用一次拉取补回可能漏掉的玩家指令与机器人回复），**不会刷新整页、不动机器人状态**；标题不变，按钮会在刷新期间显示「刷新中…」并防止连点。
- **控制台看得见玩家指令**：管理员（owners）、**传送白名单管理员（tpAdmins）**与白名单玩家（friends）下发的指令，不管走**公屏**（带 `!` / 全角 `！`）还是**私聊**（主管可省前缀），控制台都会打一行中文：`收到公屏指令 ← 玩家名（管理员）：!状态`；同时进面板的「控制台日志」窗口。同一条公屏指令多个机器人只记一条；白名单玩家的普通闲聊、陌生人的指令都不记（不刷屏）。
- **指令折叠菜单**：①每个机器人卡片里的指令按「常用 / 移动·朝向 / 家·传送 / 瓶子·攻击 / 账号」分组折叠（默认只展开「常用」），3 秒刷新也不会把你展开的菜单收起；②白名单区里那排**「白名单组可用指令」勾选框**（约 19 条）也改成折叠（点标题展开勾选）；白名单窗口本身保持常显，不折叠。
- **内存保护（稳定在线：快满先自动清理，尽量不掉线）**：启动脚本按物理内存自动设 Node 堆上限（如 8G 内存 → 4096MB）；每 5 分钟那行状态后面附「内存 x/y MB」，方便看涨没涨；平时每 5 分钟卸载离自己很远的旧区块。堆用量到上限 **78%** 自动**就地清理**（卸远处区块 + 强制 GC，机器人保持在线）→ **85%** 更狠（只留身边 2 区块 + 丢掉怪/动物实体，玩家与掉落物保留）→ 只有清完仍然 ≥ **95%** 才优雅重启兜底（`start.bat` 会在 5 秒后拉起；正常情况走不到这一步）。可调：`perf.memory.*`（阈值）/ `perf.keepChunks` / `perf.chunkTrimMs`
- **内存一直涨怎么查（两个现成工具）**：①双击 `诊断内存.bat` 启动——用同样的 Node 与堆上限，额外每分钟往 `logs\runtime\当天.log` 写一行「内存明细」（堆/常驻/句柄 + 每个账号的 实体数·区块数·监听器数·协议监听数·记分板条目·bossbar·队伍·发送队列），跑 30 分钟以上（最好跨过一次服务器例行重启）；②双击 `收集诊断包.bat` 一键把 `logs\runtime` + `src` + `config` 打包成桌面上的 `bot诊断包.zip` 发出来，就能定位到底是哪一项在涨（不会打包 `auth-cache` 登录令牌）。
- **26.x 版本服务器兼容**：针对 1.21.9+（协议 773+/26.x）服务器每 tick 要求客户端确认 `tick_end` 的机制做了自动补发（进世界后每 50ms 一个），不会被新版反作弊判「非法移动」踢出；旧版本服务器自动跳过此逻辑。被踢时日志会记录服务器返回的**原始原因 JSON**（含 translate key），一眼定位原因
- **踢出/断线原因全记录**：每次断线日志写明原因（被踢/超时/协议错误/主动重连），配合指数退避与服务器的在线探测（`serverWatch`），服务器例行重启后能自动回到线上

## 游戏内指令（默认前缀 `!`，**全角 `！` 同样识别**；管理员私聊可省略前缀）

> **「仅私聊」= 公屏发来一律静默忽略、不执行也不回复**（原因见上方功能总览）。私聊发即可，管理员私聊还能省掉 `!`。被加入「公屏组」的玩家可在公屏触发「仅私聊」类指令（面板开关）。

| 指令                | 别名                  | 发送方式    | 说明                                                                                                                                                                                                |
| ----------------- | ------------------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `!状态`             | status              | **仅私聊** | 坐标/血量/饥饿/维度/背包/在线时长                                                                                                                                                                               |
| !回家 1             | home                | **仅私聊** | 经传送队列回家（家名不填 = `home 1`）                                                                                                                                                                          |
| `!跟随 <玩家>`        | follow              | **仅私聊** | 持续跟随，`!停止` 结束                                                                                                                                                                                     |
| `!去 <玩家>`         | goto                | **仅私聊** | 走到玩家附近                                                                                                                                                                                            |
| `!停止`             | stop                | 公屏可用    | 取消任务、停止跟随、复位（全服急停）                                                                                                                                                                                |
| `!说 <内容>`         | say                 | 公屏可用    | 以普通聊天发到服务器公屏（多个机器人同时在线时同一句只发一次）                                                                                                                                                                   |
| `!左转 [角度]`        | turnleft            | **仅私聊** | 原地左转，默认 90°（配合 `!攻击` 调准星方向）                                                                                                                                                                       |
| `!右转 [角度]`        | turnright           | **仅私聊** | 原地右转，默认 90°                                                                                                                                                                                       |
| `!俯视 [角度]`        | lookdown / 下视       | **仅私聊** | 把视线调到**水平向下 x 度**（只改俯仰、不移动）：**正数向下看**（`30` = 向下 30°）、**负数向上看**（`-30` = 向上 30°）、`0` = 平视；范围 -90～90，留空 = 30°（向下）。从水平算的绝对角度（不叠加），配合 `!攻击` 用来对准。**面板卡片上也能填**：在「俯视角度」输入框里填数字（可填负数），再点「移动 / 朝向」里的「俯视」按钮 |
| `!瞄 <x> <y> <z>`  | aim / 瞄准            | **仅私聊** | 把头转向指定坐标（只摆头、不移动）                                                                                                                                                                                 |
| `!移动 x y z [距离]`  | move / 走到           | **仅私聊** | 移动到坐标，默认距目标 0.3 格停止；也可 `!移动 东/西/南/北 <格数>` 按世界方向走                                                                                                                                                  |
| `!清空`             | clear / 丢光          | **仅私聊** | 一次性丢出**全部**物品（含盔甲槽 5-8、主背包、快捷栏、副手），整叠丢；丢期间临时抑制拾取，避免被别的机器人或自己立刻捡回                                                                                                                                  |
| `!切 <1-9>`        | hotbar / 快捷栏        | **仅私聊** | 切换快捷栏到第几格                                                                                                                                                                                         |
| `!副手`             | offhand / 换副手       | **仅私聊** | 主手当前物品 ⇄ 副手（主手为空则把副手物品拿回）                                                                                                                                                                         |
| `!丢`              | toss / 丢掉           | **仅私聊** | 把主手和副手物品整组丢出（哪个有丢哪个）                                                                                                                                                                              |
| `!右键`             | use                 | **仅私聊** | 主手右键一次                                                                                                                                                                                            |
| `!持续右键`           | continuoususe / 持续键 | **仅私聊** | 副手+主手同时连点（约每 300ms 一轮）；**再发一次停止**，`!停止` 也能停                                                                                                                                                       |
| `!装备`             | equip / 穿甲          | **仅私聊** | 把背包里的头盔/胸甲/护腿/靴子穿上（该槽位已有装备则不更换）                                                                                                                                                                   |

## 使用方法

1. 把整个文件夹拷到电脑上（**无需安装 Node.js**：`runtime\node.exe` 是自带运行时，`node_modules\` 依赖也已附带）；
2. 双击 `start.bat` 即可启动并自动打开控制面板；也可在终端执行 `runtime\node.exe src\main.js`（系统已装 node 时也可用 `node src\main.js`）；
3. 按下面「登录与账号配置」添加你的账号。

### 登录与账号配置（详细）

**方式一：面板添加（推荐，不用改任何文件）**

1. 打开控制面板（启动后自动弹出的网页，默认 `http://127.0.0.1:8848`）；
2. 在「添加账号」区填写：**账号名**（正版=微软账号玩家名 / 离线服=任意名字）、登录方式选**正版**或**离线**、**服务器 IP**（可带端口，留空用默认服务器）；
3. 点「添加」，机器人立即尝试进服。

**方式二：改配置文件 `config/accounts.config.js`**

```js
module.exports = {
  server: { host: '你的服务器地址', port: 25565 },   // 默认服务器
  accounts: [
    { username: '玩家名', enabled: true, auth: 'microsoft' },  // 正版
    // { username: '离线名', enabled: true, auth: 'offline' },  // 离线
  ],
}
```

**正版（microsoft）授权流程 —— 每个账号只需做一次：**

1. 启动后控制台/日志会打印一条：`【正版授权】请打开 https://www.microsoft.com/link 输入代码：XXXXX-XXXXX`；
2. 浏览器打开 **https://www.microsoft.com/link**，输入上面的代码，用**该账号对应的微软账号**登录并确认；
3. 授权成功后机器人自动进服。令牌缓存保存在 `auth-cache\` 目录，**之后重启、掉线重连全部自动续期，不用再授权**；
4. **换电脑后令牌失效**（缓存绑定机器），新电脑上会重新走一遍设备码流程；
5. 面板里随时可用卡片上的「正版/离线」下拉一键切换登录方式（切换后自动重连生效）。

**离线（offline）模式：** 仅适用于关闭正版验证的服务器，填任意用户名即可，无授权步骤。

**首次注意事项：**

- 有些服务器首次进服需要在游戏内**加白名单/验证**，若被服务器拒绝请先在服务器侧完成验证再重启机器人；
- 有登录插件（AuthMe 类）的服务器可在配置 `autoAuth.password` 填密码，机器人会自动 `/login`、`/register`（没配密码则该功能不启用，日志与面板中密码一律打码显示）；
- 白名单玩家名加进面板「白名单管理」并勾选指令权限后，对方才能在游戏内给机器人发指令。

### 本地离线测试

- 启动离线服务器：`_research\local-server\start-server.bat`
- 机器人连本地：`node src/main.js config/local-offline.config.js`
- 状态面板（本地配置已开启）：http://127.0.0.1:8848
